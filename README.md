# Up to You — Interactive table prototype

Touch-table menu prototype for a restaurant with dynamic allergy/diet filtering.

## Screens
1. **Filters** — 15 icons; the 3 highlighted ones (milk, gluten, white meat) are editable in this demo.
2. **Menu** — each dish is flagged ingredient by ingredient against the selected filters.
3. **Dish detail** — original vs. modified dish; swap or keep each ingredient.

## Files
- `index.html` — markup
- `styles.css` — styles
- `app.js` — logic (filters, menu states, dish editing, side drawer)
- `images/` — icons, logo and dish photos

No build step, no dependencies. Open `index.html` in a browser. All images live in `images/`.
